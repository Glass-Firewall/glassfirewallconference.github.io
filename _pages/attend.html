Come as you are

A conference built for learning

The day includes technical talks, guided practice, career stories, and time to meet other attendees, speakers, and community groups. No one is expected to arrive as an expert, and there is room for questions at every level.

Beginner-friendly sessions

Speakers start with the basics and show how the ideas are used. You are welcome even if you have never opened a security tool.

Hands-on workshops

Many sessions let you follow along, try things for yourself, and ask for help when you need it.

Career stories

Researchers, engineers, and security leaders talk about how they got started and what they learned along the way.

Time to meet people

You can talk with peers, mentors, and community organizations. You do not need to arrive knowing anyone.

Before conference day

A simple preparation checklist

Requirements change from year to year, so check the official event listing before you attend.

Recommended essentials

  • A laptop and charger if you want to participate in technical exercises
  • Any accounts or software named on the current event page
  • A notebook or note-taking app
  • A few questions you would like to ask speakers or peers
  • Comfortable clothing and anything you need for a full conference day
Frequently asked questions

Know before you go

Do I need cybersecurity experience?

No. Sessions are built to be useful for beginners, and experienced attendees are welcome too. The Get Started learning hub can help you prepare, but it is not required.

Who is the conference for?

Glass Firewall is for women interested in cybersecurity and security research. Registration rules and capacity can change by event, so check the listing for the current year.

Is attendance free?

The goal is to keep Glass Firewall free for attendees. Check the current registration page for final details.

Is the conference in person or virtual?

The format changes by year. The 2023 event included a virtual option, while later events were held in person. Check the current event page before making travel plans.

Should I bring a laptop?

Bring a laptop and charger if you want to follow along during hands-on workshops. You can still learn from presentations and conversations without one unless a particular session says otherwise.

Do I need to install anything beforehand?

Some conference years ask attendees to install tools such as Burp Suite or create training accounts. Preparation instructions will appear on the official event listing. Complete downloads and account setup before arriving when possible.

Will food be provided?

Food arrangements depend on the venue and year. Check the event listing or contact the team if you need information for dietary planning.

How do I request an accessibility accommodation?

Contact the organizing team as early as you can. Tell us what you need so there is time to work with the venue and event team.

Will photographs be taken?

Past events have been photographed. Ask the event team about the current photography policy and how to indicate that you do not want to appear in event photos.

What if I register and can no longer attend?

Use the cancellation option in your registration confirmation or contact the event organizer. Releasing your place early may allow someone on a waitlist to attend.

Find the latest event information

The event listing has the latest date, venue, registration, and workshop information for each year.
